# Capa do Meu Álbum

Atividade 01 do portfólio de Felipe Rezende Baroncelli.

O álbum interativo **Camada por camada** reúne uma capa, cinco faixas e uma faixa bônus. Os textos relacionam impressão 3D, valores, habilidades, medos, sonhos e a influência do meu pai.

## Abrir a atividade

[Acessar o álbum](https://felipe-rbaroncelli.github.io/capa-do-meu-album/)

No Game Boy, A avança, B volta, SELECT mostra a explicação da capa e START alterna entre o álbum e a entrega.

## Arquivos

- [index.html](index.html) reúne o álbum, as ilustrações SVG, os estilos e a navegação.
- [README.md](README.md) apresenta a atividade.

Para visualizar no computador, baixe o repositório e abra o index.html no navegador. As fontes externas usam Google Fonts.
